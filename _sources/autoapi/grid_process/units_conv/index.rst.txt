.. py:function:: consistency_check(datasets: collections.abc.Sequence[xarray.Dataset], check_vars: bool = True) -> dict[str, dict[str, str]]

   Checks that the input datasets have same data variables and units. If it is
   the case, returns the 'units' attributes of each data variable otherwise
   raises an error.

   :Parameters: * **datasets** (*sequence of xarray.Dataset*) -- each data variable in the datasets must have a 'units' attributes
                * **check_vars** (*bool, optional*) -- if False, allows datasets to have different variables, but common ones
                  must have same units. Default is True

   :returns: **out** -- contains the 'units' attribute of the data variables in the input
             datasets. In case same units are specified in various format, the
             dominant format is kept if there is one otherwise the format from the
             first dataset in the input sequence
   :rtype: dict

   :raises UnitsError: if same variables across the input datasets have different units
   :raises ValueError: when ``check_vars=True`` and the input datasets do not have exact same
       set of variables


.. py:function:: units_check(datasets: collections.abc.Sequence[xarray.Dataset]) -> None

   Check that the data variables in the datasets all have same single units.

   :raises UnitsError: if any variable in any of the input datasets have different units
