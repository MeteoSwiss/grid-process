.. py:function:: reproject(x_coords: numpy.typing.NDArray[numpy.floating], y_coords: numpy.typing.NDArray[numpy.floating], src_crs: pyproj.CRS | str, dst_crs: pyproj.CRS | str) -> tuple[numpy.typing.NDArray[numpy.float64], numpy.typing.NDArray[numpy.float64]]
                 reproject(x_coords: list[float], y_coords: list[float], src_crs: pyproj.CRS | str, dst_crs: pyproj.CRS | str) -> tuple[list[float], list[float]]
                 reproject(x_coords: tuple[float, ...], y_coords: tuple[float, ...], src_crs: pyproj.CRS | str, dst_crs: pyproj.CRS | str) -> tuple[tuple[float, ...], tuple[float, ...]]

   Reprojects `x` and `y` coordinates from a source CRS to a new specified
   one.

   :Parameters: * **x_coords** (*numpy.ndarray, list or tuple*) -- contains `x` coordinates.
                * **y_coords** (*numpy.ndarray, list or tuple*) -- contains `y` coordinates
                * **src_crs** (*pyproj.CRS of the source or equivalent string*) -- The value can be anything accepted by
                  pyproj.CRS.from_user_input, such as an authority string
                  (e.g. "EPSG:4326") or a WKT string
                * **dst_crs** (*pyproj.CRS of the destination or equivalent string*) -- The value can be anything accepted by
                  pyproj.CRS.from_user_input, such as an authority string
                  (eg "EPSG:4326") or a WKT string

   :returns: * **x_coords_new** (*numpy.ndarray, list or tuple of float64*) -- same as input ``x_coords`` in the new CRS and cast as float64
             * **y_coords_new** (*numpy.ndarray, list or tuple of float64*) -- same as input ``y_coords`` in the new CRS and cast as float64
