set_grid_mapping(ds: xarray.Dataset) → xarray.Dataset[source]#

Set grid_mapping attribute according to internal conventions when the input grid follow CF conventions (grid mapping encoded as a data variable). The data variable encoding the grid mapping is removed.

get_spatial_dims(grid: xarray.Dataset | xarray.DataArray) → tuple[str, ...][source]#

Returns names of spatial dimensions according to the possible options defined in the config (could be overwritten by setting appropriate env variable) or according to CF conventions. The returned tuple has size one in case of unstructured grid otherwise contains dimension names in the order (y, x).

get_spatial_coords(grid: xarray.Dataset | xarray.DataArray) → tuple[str, str][source]#

Returns names of non-dimension spatial coordinates according to the possible options defined in the config (could be overwritten by setting appropriate env variable) or according to CF conventions. The returned tuple contains coordinate names in the order (y, x).

get_flat_dim(grid: xarray.Dataset | xarray.DataArray) → str | None[source]#

Returns spatial dimension name for an unstructured grid according to the possible options defined in the config (could be overwritten by setting appropriate env variable).

get_latlon_coords(grid: xarray.Dataset | xarray.DataArray, nondim: bool = True) → tuple[str, str] | None[source]#

Returns names of latitude and longitude coordinates if they exist according to the possible options defined in the config (could be overwritten by setting appropriate env variable) or according to CF conventions. The returned tuple contains coordinate names in the order (latitude, longitude). When nondim is True (default), only checks coordinates that are non-dimensional.

get_latlon_dims(grid: xarray.Dataset | xarray.DataArray) → tuple[str, str] | None[source]#

Returns names of latitude and longitude dimensions if they exist according to the possible options defined in the config (could be overwritten by setting appropriate env variable) or according to CF conventions. The returned tuple contains coordinate names in the order (latitude, longitude).

get_surf_alt(grid: xarray.Dataset | xarray.DataArray) → str[source]#

get_poi_alt(poi_info: geopandas.GeoDataFrame) → numpy.typing.NDArray[numpy.float32][source]#

Returns POIs altitudes from poi_info according to the column names defined in the config (could be overwritten by setting appropriate env variable) or from a “z” geometry. Altitude data is expected to be in meters above sea level.

get_coords_name_crs(grid: xarray.Dataset | xarray.DataArray, spatial_dims: tuple[str, ...] | None = None) → tuple[str, str, pyproj.CRS][source]#

Get correct coordinate names and CRS according to supported conventions. When non-dimensional longitude and latitude coordinates arrays are present, these are used instead of the native spatial dimension coordinates.

Parameters:

  • grid (xarray Dataset or DataArray) – contains spatial horizontal coordinates. Must have a “grid_mapping” or “crs” attribute referencing the spatial dimensions unless longitude and latitude coordinates are present.

  • spatial_dims (tuple of string(s), optional) – name of the grid spatial dimension(s). Has size one in case of unstructured grid otherwise contains dimension names in the order (y, x). If not provided, calls get_spatial_dims()

Returns:

  • grid_y (str) – name of the northward coordinate. Usually ‘x’ or ‘longitude’

  • grid_x (str) – name of the eastward coordinate. Usually ‘y’ or ‘latitude’’

  • grid_crs (pyproj CRS) – pyproj representation of input grid coordinate reference system
